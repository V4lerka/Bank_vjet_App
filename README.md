## Описание🪪
**Проект v-jetApp** - это новая фича для личного кабинета клиента одного из крупных банков💰. Это виджет, который 
показывает несколько последних успешных банковских операций клиента. Нам доверили реализовать этот Python-проект🐍, 
который на бэкенде будет готовить данные для отображения в новом виджете.

## Описание функционала:🪄
* Модуль **masks.py** содержит функцию *get_mask_account*, которая маскирует номер банковского счета
* Модуль **widget.py** содержит функцию *mask_account_card*, которая принимает номер банковского счета или карты и 
возвращает в замаскированном виде. А еще там есть функция *get_date*, которая принимает дату в формате 
<2024-03-11T02:26:18.671407> и возвращает формат <ДД.ММ.ГГГГ>
* Модуль **processing.py** содержит функцию *filter_by_state*. Функция принимает список словарей и опционально значение 
для ключа state (по умолчанию 'EXECUTED') и возвращает новый список тех словарей, у которых ключ state соответствует 
указанному. Функция *sort_by_date* принимает список словарей и параметр, задающий порядок сортировки (по умолчанию — 
убывание) и возвращает новый список, отсортированный по дате (date).
